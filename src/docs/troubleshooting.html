Troubleshooting

Start with skyland doctor: it checks the whole install (permissions, SIP, payload, sudoers, bar, border) and prints the fix for each problem.

A window is invisible

skyland restores every window on quit and on SIGTERM; on a crash or kill -9, the Dock payload shows the windows it changed again. If one is still missing:

skyland enable off   # windows parked in a corner come back
killall Dock         # resets alpha and transforms set by the payload (then: skyland sa load)

No corners, opacity or animations

The payload is not loaded. skyland-sa send ping must answer ok fade …; if not:

skyland sa load

It is gone after a reboot or killall Dock unless the LaunchAgent injects it. Without SIP partly off it cannot load at all: see Full effects.

Shortcuts do nothing

Check that Skyland is allowed in System Settings › Privacy & Security › Accessibility. Started from a terminal, macOS asks for the terminal instead: start it with open or skyland env.

Two windows share a workspace after clicking another app

Several macOS Spaces exist. skyland expects one per display: remove the others in Mission Control.

The overview shows app icons, not windows

Allow Skyland in Screen Recording (System Settings › Privacy & Security). Windows of hidden workspaces show their last picture once you have visited them.

Building from source fails

  • 'async' call cannot occur in a defer body: the build used Xcode's Swift. Use swiftly run swift build (or bin/skyland-build): skyland needs Swift 6.4.
  • libSystem.B.tbd: unknown architecture: a newer SDK than the toolchain knows. Prefix with SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk.

Still stuck? Open an issue with the output of skyland doctor.
