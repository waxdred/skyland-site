Install

You need an Apple Silicon Mac with macOS 15 or later and Homebrew. Everything else comes with skyland install.

Quick start (SIP on)

brew install waxdred/tap/skyland
skyland install     # dependencies, signing identity, config in ~/.config, start
skyland doctor      # what works, what is missing, how to fix it

Then allow Skyland in System Settings › Privacy & Security › Accessibility, and Screen Recording for the overview thumbnails and the media widget.

Start it with open or skyland env, not from a terminal: launched from a terminal, macOS gives the permission request to the terminal and Skyland keeps losing it.

After brew upgrade skyland, skyland env restarts it. Your config in ~/.config is kept.

From source

git clone --recurse-submodules https://github.com/waxdred/skyland.git
cd skyland
bin/skyland-install   # dependencies, Swift (swiftly), signing identity, build, CLI, start
skyland doctor

From a release, without building

Download skyland-<version>.zip from Releases, unzip it and run bin/skyland-install in it. No Swift toolchain needed.

Full effects (SIP partly off)

Rounded corners, opacity, dim, animations and fades go through a scripting addition injected into Dock, as yabai does. It needs System Integrity Protection partly disabled and an arm64e boot-arg. Everything else works without it.

  1. Boot into Recovery (hold the power button), open Terminal, run 
    csrutil enable --without fs --without debug --without nvram
  2. Back in macOS: 
    sudo nvram boot-args=-arm64e_preview_abi
sudo reboot
  3. Build and inject the payload: 
    skyland sa build && skyland sa load   # asks for your password once
skyland doctor                        # "payload loaded in Dock"

skyland sa load offers a sudoers rule pinned to the loader's sha256, so the payload is injected again at login without a password. If Skyland ever crashes, the payload shows the windows it changed again (alpha 1, real frame, no dim).

Disabling parts of SIP lowers the protection of your Mac. Do it on a machine you own and understand the trade-off; skyland works without it.

First steps

  • alt-t or alt-enter opens a terminal, cmd-1…cmd-0 switch workspaces, cmd-shift-1… move the window there.
  • alt-shift-h shows every shortcut, read from your config.
  • alt-i opens the settings window: gaps, decoration, animations, wallpaper, keys and rules, applied live.
  • alt-r turns window management off and on: your windows go back to stock macOS while off.

Autostart

Nothing is set up to start at login without you asking. A LaunchAgent injects the payload (with the sudoers rule above) and starts skyland. Save this as ~/Library/LaunchAgents/com.waxdred.skyland.plist:

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key><string>com.waxdred.skyland</string>
    <key>RunAtLoad</key><true/>
    <key>EnvironmentVariables</key>
    <dict><key>PATH</key><string>/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin</string></dict>
    <key>ProgramArguments</key>
    <array>
        <string>/bin/bash</string>
        <string>-c</string>
        <string>sleep 5; L=/Library/ScriptingAdditions/skyland.osax/Contents/MacOS/loader; sudo -n "$L" "$(pgrep -x Dock)"; "$HOME/.local/bin/skyland" env</string>
    </array>
    <key>StandardErrorPath</key><string>/tmp/skyland-login.log</string>
</dict>
</plist>
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.waxdred.skyland.plist   # enable
launchctl bootout gui/$(id -u)/com.waxdred.skyland                                   # disable

With SIP on, drop the sudo -n part: there is no payload to inject. skylandbar has its own: skylandbar --service install.

Uninstall

skyland uninstall   # everything but the repo, asks first
sudo rm /private/etc/sudoers.d/skyland   # if you added the sudoers rule
