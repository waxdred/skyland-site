Configuration

skyland reads ~/.config/aerospace/aerospace.toml. Every AeroSpace option works; the keys below are skyland's. Most of them are also in the settings window (alt-i), which applies them live and writes them back to the file with its comments kept. After editing by hand: skyland reload-config.

Layout and mouse

dwindle = true                 # a new window splits the focused one along its longest side
dwindle-smart-split = true     # ...on the side of the cursor (Hyprland smart_split)
master-ratio = 55              # master layout: master width in percent (Hyprland mfact)
master-orientation = 'auto'    # left | center | auto (center on ultrawide screens)
master-workspaces = []         # workspaces in the master layout at the very first start
floating-center-percent = 70   # 'layout floating' on a tile: N% of the monitor, centered
mouse-modifier = 'alt'         # alt + left drag moves, alt + right drag resizes, anywhere on a window
bar-height = 32                # keep windows below the bar on every screen; a bar can send it
mode-indicator = 'hud'         # binding modes other than main: 'hud' | 'bar' | 'off'
key-mapping.preset = 'input-source'  # letters follow the keyboard layout (AZERTY / QWERTY)
smart-gaps = false             # a single tiled window: no gaps
smart-border = false           # ...and no border nor rounding
gaps.inner.horizontal = 8
gaps.inner.vertical = 8
gaps.outer.top = 8

key-mapping.preset = 'input-source' keeps alt-m on the key that types “m” when you switch between French AZERTY and English QWERTY; digits keep their physical position. The hypr profile puts 4 workspaces on each screen (1–4, 5–8, 9–12, left to right).

Decoration

Corners, opacity, dim and shadows need the Dock payload; the border uses JankyBorders or skyland's own rotating gradient.

[decoration]
rounding = 8
active-opacity = 100           # percent
inactive-opacity = 85
dim-inactive = 20              # darken unfocused windows, percent, 0 = none
border-width = 2               # focused window border in the theme accent, 0 = none
border-rotate-ms = 4000        # the border gradient turns once per N ms, 0 = static
blur = 5                       # Ghostty background blur, 0 = none
shadow = 'on'                  # on | off | floating (only floating windows keep one)
group-bar-height = 22          # accordion containers become groups with a tabs bar, 0 = AeroSpace accordion
ui-style = 'glass'             # skyland's panels: metal (blur) | glass (Liquid Glass)

alt-o cycles the inactive opacity through 100, 90, 80 and 70.

Animations

[animations]
enabled = true
preset = 'hyprland'            # hyprland | slide | gnome | vertical | cyberspace, or a list
bezier = ['overshot, 0.05, 0.9, 0.1, 1.05']   # hyprland.conf `bezier =` lines
animation = [                                # hyprland.conf `animation =` lines, over the preset
  'windows, 1, 5, overshot, popin 80%',
  'workspaces, 1, 6, default, slidevert',
]

Without a preset or lines, the simple keys apply: windows-ms, windows-bezier, workspaces-ms, workspaces-bezier, fade-ms, fade-bezier. Hyprland speeds are in deciseconds: speed 5 = 500 ms.

Themes and wallpaper

[theme]                        # GTK colors.css files: @define-color key #rrggbb;
dark = '~/.config/skyland/themes/43pr-catppuccin-mocha.css'
light = '~/.config/skyland/themes/43pr-white.css'

[wallpaper]
dir = '~/Pictures/Wallpapers'
dynamic-colors = true          # theme colors from the wallpaper (matugen)
prefer = 'saturation'
scheme = 'auto'                # monochrome for grayscale wallpapers, else content
auto-mode = true               # light theme for a bright wallpaper, dark for a dark one

18 themes from 43PR ship in ~/.config/skyland/themes/: copy one and edit the colors to make yours. alt-l toggles light and dark, alt-shift-l opens the theme picker, alt-w the wallpaper picker. The current colors are also in ~/.cache/skyland/theme.env for your own scripts.

Wallpapers from wallhaven, no account needed:

skyland-wallpaper fetch                        # uploads of the 43PR user
skyland-wallpaper fetch <user>/favorites/<id>  # one public collection, into its own folder
skyland-wallpaper set ~/Pictures/Wallpapers/city.jpg

macOS appearance

[appearance]
sync-dark-mode = true          # macOS dark / light follows skyland
accent = 'theme'               # the macOS accent closest to the theme accent | 'off' | blue, purple...
highlight = 'theme'            # text selection color | 'off' | a preset | '#rrggbb'

The values found before the first change are kept: skyland appearance restore puts them back.

Lock screen and media widget

[lock]
name = 'Neo'                   # lock screen name, default: your macOS full name
blur = 4

[media]
opacity = 92
style = 'classic'              # or 'audioware': a light wave, its center line is the progress

skyland lock install installs the screen saver; alt-tab locks, alt-m toggles the media widget.

Window rules

[[on-window-detected]]
if.app-id = 'com.apple.calculator'
run = 'layout floating'

[[on-window-detected]]
if.app-id = 'com.apple.finder'
run = ['layout floating', 'window-rule size 60% 70%', 'window-rule center',
       'window-rule opacity 95 85', 'window-rule rounding 14', 'window-rule noanim']

See window-rule and Coming from Hyprland.

Binding modes

Modes are Hyprland submaps. While a mode other than main is active, mode-indicator = 'hud' shows its name and keys at the bottom of the screen (drag it, the place is remembered).

[mode.main.binding]
alt-shift-r = 'mode resize'

[mode.resize.binding]
h = 'resize width -50'
l = 'resize width +50'
e = 'balance-sizes'
esc = 'mode main'

With mode-indicator = 'bar', a bar shows it instead: the skyland_mode event is triggered with MODE=<name> (empty back in main).

SketchyBar

skyland works with skylandbar out of the box. With SketchyBar, keep your sketchybarrc and add one line at its end:

[ -x "$HOME/.local/bin/skyland" ] && "$HOME/.local/bin/skyland" bar >/dev/null 2>&1 &

It replaces the macOS Spaces items with workspace.1…workspace.12, writes the focused window in an item named window_title, recolors the bar with the theme, and fires skyland_update on focus and workspace changes for your own items.
