skyland docs

skyland is a fork of AeroSpace: everything AeroSpace does still works (virtual workspaces, tree layouts, the CLI, the TOML config), and skyland adds the layouts, decoration, animations and desktop pieces of a Hyprland setup.

Install

Homebrew, source or release zip; permissions; the optional Dock payload for window effects.

How it works

The window manager is AeroSpace's Swift app, with skyland's additions in Sources/AppBundle/skyland/. Windows are moved and resized through the public Accessibility API. What that API cannot do (corner radius, the alpha of other apps' windows, transforms for animations) goes through a scripting addition injected into Dock: Dock owns the universal SkyLight connection, so changes sent from there apply to every app's windows.

  • Animations and fades are stepped by the payload in sync with the display, through one SkyLight transaction per frame. WindowServer-side animations are never used: an animated alpha crashed WindowServer when a window closed mid-fade.
  • The payload remembers the windows it changed. If Skyland ends for any reason, it shows them again.
  • Workspaces are virtual: windows of hidden workspaces are parked in a screen corner, as AeroSpace does. No macOS Spaces, no Mission Control animations.

Everything goes through one CLI, skyland: its own scripts (skyland theme pick, skyland doctor) and every window manager command (skyland workspace 3, skyland list-windows --all).
