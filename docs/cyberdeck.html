skyland-cyberdeck

Cyberpunk HUD pieces for macOS: neon colors, cut corners, glow, scanlines. Made for skyland, works with any window manager. Source: waxdred/skyland-cyberdeck.

brew install waxdred/tap/skyland-cyberdeck

Apps launcher

A curved column of apps around the selection. Type to search (prefix, word start, substring, then fuzzy), apps you launch often come first. ↑ ↓ or scroll, return or a click to launch, esc to close.

skyland-cyberdeck launcher   # toggle

HUD

A deck over the desktop with real data only: clock and calendar, Wi-Fi, Bluetooth and AirDrop, brightness and volume, CPU, RAM, network, disk and battery, herdr agents, the last messages and quick launch. Click a card to open its app, drag it by its header. Nothing runs while it is closed.

skyland-cyberdeck hud           # toggle
skyland-cyberdeck config init   # writes ~/.config/skyland-cyberdeck/config.toml

Audio deck

The live signal of what plays, on a neon grid; now playing with artwork; the output devices as numbered ports; the apps playing sound now. space play / pause, ← → tracks, ↑ ↓ volume.

skyland-cyberdeck audio   # toggle

Messages and scripting API

The macOS Notification Center history merged with the messages your scripts send, as neon contact cards.

skyland-cyberdeck notify -t TITLE [-b BODY] [-s SUBTITLE] [-a APP] [--seconds N] [--quiet]
skyland-cyberdeck list [--json] [--limit N] [--all]
skyland-cyberdeck dismiss <id> | --all

# a long command is done
make build; skyland-cyberdeck notify -t "make build" -b "exit $status" -a com.mitchellh.ghostty
# unread count for a bar item
skyland-cyberdeck list --json | jq length

Themes

skyland-cyberdeck theme list            # cyberpunk, skyland, then the skyland themes
skyland-cyberdeck theme skyland         # follow the current skyland theme
skyland-cyberdeck theme 43pr-dracula    # a skyland theme by name, or a .css file
