01 / Window management

A different way to use your Mac.

Skyland brings a Hyprland-inspired workflow to macOS, combining tiling, workspaces, window groups and fluid transitions. It is a fork of AeroSpace: everything AeroSpace does stays, with what makes Hyprland feel like Hyprland on top.

  1. 01

    Dwindle & smart split

    New windows split the focused tile on the side of the cursor. alt j toggles the split, alt + drag swaps tiles.

  2. 02

    Window groups

    alt g turns a container into tabs with a tabs bar on top; alt n cycles through them.

  3. 03

    Scratchpads & rules

    alt s slides a scratchpad over the layout. Window rules float, size or send apps to a workspace.

Everything else Skyland does
  • Workspaces on cmd 1…0, trackpad swipe between them, overview on cmd ↑
  • Master layout per workspace, swap with the master
  • Hyprland animations: presets or bezier lines pasted from a hyprland.conf
  • Window decoration: rounded corners, active / inactive opacity, dim, focused border
  • 43PR themes as CSS files, colors generated from the wallpaper
  • Binding modes (Hyprland submaps) with a HUD of their keys
  • Settings window, key recorder and rules editor, applied live
  • Window switcher, wallpaper picker, lock screen, media widget

03 / System experience

The system, reimagined.

SkylandBar extends the desktop with a macOS-like system bar in Liquid Glass. It speaks SketchyBar's language, so existing configs and plugins run unchanged.

Workspace 3 ghostty nvim btop

The bar is a real screenshot; the popup below it is an illustration of a glass popup.

  • Liquid Glass

    Items, groups and popups in glass: Apple's on macOS 26, a refraction shader on older versions. A selection lens flows between workspaces.

  • Skyland built in

    Workspaces with their apps, the focused window title, modes — read from Skyland's socket, no script to wire.

  • Windows below it

    The bar tells Skyland its height. No value to keep in sync, and a TOML config reloaded live.

Built for the curious

Built, not bought.

A personal experiment in reshaping the macOS experience — one window, one animation and one idea at a time.

  1. inspiration

    Hyprland, on a Mac

    Dwindle, groups, submaps and bezier lines come straight from Hyprland; the look from the 43PR dotfiles.

  2. motion

    Animations stepped by hand

    A scripting addition in the Dock steps window transforms and alpha every 8 ms. The animation engine has its own browser lab.

  3. native

    Exploring macOS internals

    Private SkyLight signatures recovered by reverse engineering the dyld shared cache. How it works.

  4. yours

    Personalisation first

    A config file, live settings, recorded keys, per-app rules, themes as CSS.

  5. coherence

    One environment

    Window manager, bar and cyberdeck share the same glass, the same accent and the same socket. Changelog.
